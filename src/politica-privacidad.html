1. Alcance y responsable

Deluxe Cars es un proyecto demostrativo para mostrar un catálogo de vehículos y funciones básicas de cuenta. Esta versión no cuenta con un servicio de atención conectado a una base de datos. Por ello, no se debe interpretar el nombre, la dirección o el correo que aparecen en la web como datos verificados de una entidad responsable.

2. Datos y almacenamiento en el navegador

Según las funciones que utilices, el navegador puede guardar en el almacenamiento local de esta web:

  • Cuenta de demostración: nombre, correo electrónico y una huella de la contraseña creada mediante un hash con sal. La contraseña no se guarda como texto normal, pero este mecanismo de demostración no debe considerarse adecuado para proteger una cuenta real.
  • Sesión: información necesaria para mantener el acceso. Puede permanecer solo en la sesión actual o guardarse en el dispositivo si marcas «Recordarme».
  • Favoritos: datos básicos de los coches que decides guardar, asociados al correo de la cuenta local.
  • Administración: coches añadidos, cambios del catálogo, vehículos eliminados y selección de coches destacados de Inicio.

Estos datos permanecen en el perfil del navegador y no se sincronizan con otros dispositivos ni se transmiten al concesionario.

3. Finalidad y formulario de contacto

El almacenamiento local permite probar las funciones de registro, inicio de sesión, favoritos y gestión del catálogo. El formulario de contacto solo comprueba que los campos tengan un formato válido: al enviarlo, muestra una confirmación y limpia los campos, pero no remite el mensaje ni sus datos a ninguna persona o servidor.

La web no implementa pagos, contratación ni envío de solicitudes comerciales.

4. Enlaces e imágenes de terceros

Algunas imágenes del catálogo pueden cargarse desde sitios externos. Si el navegador solicita una de esas imágenes, el proveedor correspondiente podría recibir datos técnicos de la conexión, como la dirección IP. La disponibilidad y las prácticas de privacidad de esos sitios no dependen de Deluxe Cars. El resto de los recursos de Bootstrap se incluye en el propio proyecto.

5. Conservación y control de tus datos

Los datos locales se conservan hasta que los elimines o borres los datos del sitio desde la configuración del navegador. Puedes cerrar la sesión desde la página de Acceso y quitar coches individualmente de Favoritos. Para borrar cuentas de demostración, selecciones y cambios de catálogo, elimina el almacenamiento de este sitio en tu navegador.

Borrar los datos del navegador es una acción local y no se puede deshacer; también elimina otros datos de demostración asociados a esta web.

6. Seguridad y uso responsable

El acceso de administrador utiliza credenciales públicas de demostración y los datos se guardan en el navegador. No uses información personal sensible, contraseñas reutilizadas ni datos que necesiten protección. No emplees las funciones de esta versión para gestionar un catálogo o cuentas reales.

7. Derechos de las personas

En un servicio real, las personas pueden ejercer los derechos que les reconozca la normativa aplicable y deben disponer de la identidad y los datos de contacto del responsable. Esta demo no recibe solicitudes ni dispone de un sistema para localizar o borrar datos en un servidor, porque no los almacena allí.

8. Contacto y cambios de esta política

Para consultas sobre la demostración, visita la página de contacto. Antes de publicar el proyecto como servicio real, se deben sustituir los datos de contacto de ejemplo e incluir la identidad del responsable, las finalidades y bases jurídicas aplicables, los plazos de conservación y los canales para ejercer derechos.
